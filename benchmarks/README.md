# Benchmarks

Frozen SahalNLP evaluations live here.

A benchmark should record:

- what capability it measures;
- how examples were selected;
- the freeze date or commit;
- scoring rules;
- whether answers have been inspected during development;
- any external systems and versions used for comparison.

A benchmark that has influenced implementation remains valuable for regression testing, but it is no longer an unseen benchmark for future superiority claims.
