# Language benchmarks

No SahalNLP language benchmark in this directory is currently eligible to be called **unseen**.

The examples in `tests/language/` are development/regression cases and were visible during Language Analysis v1 implementation.

The first true frozen benchmark should be selected later from separately sourced Somali, English/non-Somali, mixed, and ambiguous material. Its examples and labels must be frozen before benchmark-specific tuning, with provenance and scoring rules recorded here.
