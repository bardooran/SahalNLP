# Data directory

This directory is for **small, reviewable project data**, not bulk corpora.

Planned tracked areas may include:

- `reviewed/` — manually reviewed examples with provenance.
- `fixtures/` — tiny test fixtures.

Large downloaded, processed, or release corpora belong in ignored local paths such as `data/raw/`, `data/processed/`, and `data/releases/` or in an external dataset store.

Every tracked dataset should document its origin, intended use, and licensing status before it is used for training or evaluation.
